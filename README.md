# Todo List App with Tags

## Site Description

Todo List App with Tags is a simple, interactive web application designed to help users organize tasks efficiently. Users can add tasks, assign them categories (tags), and filter tasks based on their status or tag. The app provides a clean and minimal interface focused on usability and productivity.

The application includes form validation, dynamic task management, and filtering features. It is built using HTML, CSS, and JavaScript, making it lightweight and easy to expand. The layout is responsive and designed to work smoothly across devices.

---

## Pages

1. Home (index.html)

   * Main interface for managing tasks
   * Includes task input form, filters, and task list display
   * Handles all interactions dynamically using JavaScript

---

## Sections

1. Header

   * Displays the title "Todo List"

2. Task Form

   * Input field for entering tasks
   * Dropdown menu for assigning a tag (School, Work, Personal)
   * Submit button to add tasks
   * Error message display for validation

3. Status Filters

   * Buttons to filter tasks by:

     * All
     * Active
     * Completed

4. Tag Filters

   * Buttons to filter tasks by category:

     * All
     * School
     * Work
     * Personal

5. Task Counter

   * Displays the number of active (incomplete) tasks

6. Task List

   * Dynamically generated list of tasks
   * Supports marking tasks as completed and managing them

---

## Key Features

* Task Creation Add tasks with optional category tags
* Tagging System Organize tasks by School, Work, or Personal
* Filtering Filter tasks by status and tag
* Form Validation Prevents empty task submissions with error messaging
* Dynamic Updates Real-time task rendering using JavaScript
* Lightweight Design Simple and fast user experience
